    Stream 1 Execution Plan (GitHub API Adapter - #24, #25, #26, #27, #28)

    We will modify core/repo_reader.py to use an adapter pattern, introducing GitHub scraping while keeping local evaluation behavior consistent.

    [MODIFY] pyproject.toml

    • Add httpx to the list of dependencies. Run uv pip install -e ".[dev]" afterward.

    [MODIFY] core/repo_reader.py

    1. Introduce the routing interface: python def get_commits(source: str = "local", days: int = 7, **kwargs) -> list: if source == "local": return _get_local_commits(days) elif source == "github": return _get_github_commits(days=days, **kwargs) else: raise ValueError(f"Unknown source: {source}")
    2. Rename current get_commits function to _get_local_commits(days: int = 7).
    3. Create _get_github_commits(days: int = 7, username: str = None, repos: list[str] = None) -> list:
    4. Calculate since using datetime.now(timezone.utc) - timedelta(days=days).
    5. Setup httpx loop for every repo in repos.
    6. Setup Authorization headers to pass GITHUB_TOKEN from os.environ if accessible. Include Accept: application/vnd.github+json and X-GitHub-Api-Version: 2022-11-28.
    7. Intercept error status codes to properly elevate:
      • 404: ValueError("Repo 'username/repo' not found or is private")
      • 429: ValueError("GitHub API rate limit exceeded")
      • 401: ValueError("GitHub API unauthorised — check GITHUB_TOKEN")
    8. Iterate over commits returning flat objects of shape: {"repo": repo_name, "message": commit["commit"]["message"], "author": commit["commit"]["author"]["name"], "date": datetime.fromisoformat(commit["commit"]["author"]["date"]), "hash": commit["sha"]}.
